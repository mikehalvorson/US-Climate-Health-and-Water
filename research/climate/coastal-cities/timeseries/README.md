# Coastal-city time series

All CSV files are generated by `scripts/normalize_coastal_cities.py` from raw
NOAA files in `../../timeseries/raw/` plus explicitly transcribed, cited scenario
tables from peer-reviewed migration studies.

## Series

- `noaa-relative-sea-level-scenarios.csv`: 2022 Interagency Task Force median
  local relative sea-level values by global scenario. `relative_sea_level_m` is
  the source value including its offset; `change_from_2020_m` is preferred for
  display because it has an explicit local 2020 chart baseline.
- `noaa-high-tide-flood-days.csv`: days per year above NOAA local minor,
  moderate, and major thresholds by decade and scenario at Virginia Key and
  Grand Isle. Grand Isle is coastal-Louisiana context, not New Orleans.
- `observed-relative-sea-level-trends.csv`: record-wide NOAA station trends and
  standard errors, converted from inches per decade to millimeters per year.
- `hauer-2100-cbsa-net-migration.csv`: selected CBSA net-migration outputs under
  a 1.8-meter 2100 stress test. These are not forecasts and have no annual path.
- `scenario-milestones.csv`: sea-level milestone dates assumed by Robinson et
  al. (2020). These study assumptions must not be relabeled as current NOAA
  projections.
- `raw-file-sha256.json`: input provenance and hashes.

Run from the climate package directory:

`python coastal-cities/timeseries/scripts/normalize_coastal_cities.py`
